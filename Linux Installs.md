# Linux Installs

This is a list of apps I like to install on most or all linux installations.

## Common

- **Fira Code Font**
- **~~neofetch~~** - archived needs replaced
- **screenfetch** - Trying to replace neofetch. May also try macchina. fastfetch is another option used by Garuda
- **openssh**
- **TLDR** - a really nice help with syntax for many apps and commands
- **VS Code [Insiders]** - Code for stable, Insiders when less mission critical
- **thefuck** - mistype correction suggestions
- **eza** ls replacement
- **Atuin** - CLI history database
- **tmux** - Terminal multiplexer | A challenger appears: Herdr
- **7zip**
- **Obsidian** - Notes
- **Remina** - Remote connection manager
- **Rustdesk** - full screen control etc 
- **Micro** - I've been transitioning from nano to micro
